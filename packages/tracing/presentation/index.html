Start with explicit tracing

Describe meaningful host operations with lazy, nested spans.

  fn() { system.env("EYG_ORIGIN") },
  fn(_) { None },

Gleam owns trace state, OTLP encoding, batching, and errors. Plinthx binds only native APIs.

Then observe evaluation and effects

eyg.run
  eyg.eval

Parent width includes child work and waiting. These are instrumented wall-clock spans, not sampled CPU usage.

OTLP/HTTP → Jaeger or any compatible collector.

The shape of a retry

// An HTTP response is a successful Fetch, even when its status is 503.
// The application decides to retry; the backoff is visible as a Sleep span.
let http = import "./http.eyg"
let port = http.port({})
let first = http.get(port, "/unavailable")
match !equal(first.status, 503) {
  True(_) -> {
    let _ = perform StandardOut("HTTP 503; waiting before retry\n")
    let _ = perform Sleep(100)
    let answer = http.require_ok(http.get(port, "/answer"))
    perform StandardOut(answer)
  }
  False(_) -> { !never(perform Abort("expected the demo's HTTP 503")) }
}

A failed effect. A successful run.

// Reading a directory as a file fails deterministically.
// The effect span is red, but handling its Error keeps the run successful.
let text = match perform ReadFile({path: "./fixtures", offset: 0, limit: 1024}) {
  Ok(_) -> { !never(perform Abort("expected the directory read to fail")) }
  Error(_) -> {
    let _ = perform StandardOut("Read failed; using the fallback\n")
    let _ = perform Sleep(60)
    match perform ReadFile({path: "./fixtures/fallback.txt", offset: 0, limit: 1024}) {
      Ok(bytes) -> {
        match !string_from_binary(bytes) {
          Ok(text) -> { text }
          Error(_) -> { !never(perform Abort("fallback was not UTF-8")) }
        }
      }
      Error(reason) -> { !never(perform Abort(reason)) }
    }
  }
}
perform StandardOut(text)

Errors describe execution

A failed ReadFile can be recovered by EYG. An unhandled Abort fails the evaluation. A returned HTTP 503 is still a successful Fetch transport response.

Execution evidence is not a task-quality score, and trace storage is not a replay log.
